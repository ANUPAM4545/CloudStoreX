# CloudStoreX Developer Scripts

This directory contains utility scripts and automation tools for developing, testing, and verifying the CloudStoreX repository.

## Available Scripts

| Script | Description |
|---|---|
| `test-all.sh` | Executes full test suites across both backend (Go) and frontend (TypeScript/Vitest). |

## Usage

Make sure scripts are executable:

```bash
chmod +x scripts/*.sh
```

Run tests:

```bash
./scripts/test-all.sh
```
