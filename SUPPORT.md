# Getting Support for CloudStoreX

We are excited that you are using CloudStoreX! Here are the best channels to get help:

## Documentation

- **Core Guide**: Check out the comprehensive docs in the [**docs/**](docs/) directory.
- **API Reference**: Read our [Storage REST API Control Plane](docs/rest-api.md) documentation.
- **Local Development**: Follow the [Local Development Guide](docs/development-guide.md).

## Bug Reports & Feature Requests

- **Bug Reports**: Open an issue on GitHub using our Bug Report template. Please include Docker compose logs and clear reproduction steps.
- **Feature Requests**: Discuss proposal ideas in GitHub Discussions before submitting a PR.
