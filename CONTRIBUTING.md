# Contributing to CloudStoreX

Thank you for your interest in contributing to **CloudStoreX**!

For detailed guidelines on local setup, branching, commit conventions (`Conventional Commits`), code style, and pull request workflows, please see our complete guide:

👉 [**docs/contributing.md**](docs/contributing.md)

## Quick Start

1. Check out our [Local Development Guide](docs/development-guide.md).
2. Ensure you run automated verification before submitting a PR:
   ```bash
   ./scripts/test-all.sh
   ```
3. Read our [Code of Conduct](CODE_OF_CONDUCT.md).
