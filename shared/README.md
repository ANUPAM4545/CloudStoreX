# CloudStoreX Shared Resources & Schemas

This directory is reserved for shared contracts across the CloudStoreX platform.

## Contents & Purpose

As CloudStoreX expands in future milestones (e.g. Metadata Engine, Policy Evaluator service), this package will host:

- **OpenAPI Specifications**: Language-agnostic REST API schemas and Swagger definitions.
- **Protobuf / gRPC Schemas**: RPC definitions for inter-service communication between the Storage Router, Policy Engine, and Metadata Engine.
- **Cross-Service Domain Contracts**: Shared error codes, metadata constants, and tenant policy schemas.
